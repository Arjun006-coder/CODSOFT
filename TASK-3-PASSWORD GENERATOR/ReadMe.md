# Task 3 - Password Generator

This project is a simple password generator developed using Python as part of the CodSoft Internship (July 2025 Batch). It allows users to generate secure, random passwords of a specified length using a mix of letters, numbers, and special characters — without using the `string` module.

## Features
- Prompts the user to input desired password length
- Uses manually defined character sets (no string module)
- Randomly generates a strong password
- Validates length and handles invalid input


## Sample Input
```bash
Enter password length: 10
```

## Sample Output
```bash
Generated Password: Af9$@kB!2q
```

## Technologies Used
```bash
- Python
- random module only
```
